# Copyright

- Every file MUST have the copyright statement below associate with it
- Exceptions to certain file (types) MAY be given to omit including the copyright statement in the file itself. This MUST be done through the `REUSE.toml`. This MAY only be done when adding the copyright statement itself would be impossible or very inconvenient. For example in `png` or `json` files.

!!! info

    License compatibility is checked by [REUSE lint](https://reuse.readthedocs.io/en/stable/man/reuse-lint.html) to prevent possible violations of the rules above.

## Copyright Statement

```text
SPDX-FileCopyrightText: <year-of-creation> CERN
SPDX-License-Identifier: GPL-3.0-or-later
```
