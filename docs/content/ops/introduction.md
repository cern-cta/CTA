# Operations

CTA is packaged and distributed as a public release, free from CERN-specific dependencies, together with a set of operations tools.
To run CTA, it goes without saying that you need a number of operators that can handle the deployment and intervene when necessary.

The pages here will cover:

- How to install the CTA RPMs
- The various tools that CTA provides for operators
- Some basics on how to set up monitoring
- Operational procedures

For any questions or doubts about the operational procedures, please visit the [Community Forum](https://cta-community.web.cern.ch).
