# Upgrading CTA Catalogue schema

## Automated procedure [recommended]

The recommended way to upgrade is to use the *schema upgrade container* provided by the CTA team. All the required tools are provided in the container, giving a seamless one-click upgrade procedure.

The instructions on how to perform the automated upgrade can be found here:
- [CTA Catalogue upgrade - automated procedure](./automated.md)

## Manual procedure

!!! warning "Warning"
    This is **not** the recommended way to upgrade the CTA Catalogue schema, given it's dependencies and complexity. Please consider the automated procedure linked above.

The procedure for a *manual upgrade* is also described here for completeness:
- [CTA Catalogue upgrade - manual procedure](./manual.md)
