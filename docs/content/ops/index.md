# Operations

Use these guides to install, configure, run, and maintain CTA and its integration with a separately managed disk system. For a new deployment, start with [Deployment Planning](deploy-and-configure/deployment/planning.md).

| I want to… | Start here |
| --- | --- |
| Plan a CTA deployment | [Deployment Planning](deploy-and-configure/deployment/planning.md) |
| Install CTA services | [Installation](deploy-and-configure/deployment/installation/index.md) |
| Configure services or find example configurations | [Service Runtime](deploy-and-configure/configuration/service-runtime.md) |
| Connect CTA to a disk system | [Disk System Integration](deploy-and-configure/integrations/index.md) |
| Initialise and verify a deployment | [Initialisation and Verification](deploy-and-configure/deployment/initialisation.md) |
| Perform routine administration | [Administration](run-and-maintain/administration/index.md) |
| Monitor service health | [Monitoring](run-and-maintain/monitoring/health-and-alerts.md) |
| Upgrade CTA | [Upgrading CTA](run-and-maintain/upgrades/cta.md) |
| Upgrade EOS or dCache | [Upgrading Disk System](run-and-maintain/upgrades/disk-system.md) |
| Tune CTA throughput or capacity | [Performance & Capacity](run-and-maintain/administration/performance.md) |
| Tune EOS disk layout or transfer policies | [EOS Performance & Disk Layout](run-and-maintain/administration/eos/performance.md) |

Choose the integration guide for your disk system; EOS-specific instructions do not apply automatically to other disk systems. [Concepts](../concepts/index.md) explains the shared terminology and architecture. Development documentation is not a prerequisite for operating CTA.

For questions and discussion, use the [Community Forum](https://cta-community.web.cern.ch).
