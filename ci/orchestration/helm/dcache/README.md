# dCache integration chart

This chart installs the upstream dCache chart together with PostgreSQL, ZooKeeper, and Kafka as one Helm release.
The dependency version is pinned in `Chart.yaml`; update it there rather than in `project.json`.
The deployment entry point is `ci/orchestration/deploy_dcache.sh`.

The development preset supplies mTLS configuration and mounts the client certificate and CA secrets generated by the CTA auth chart.

## Startup ordering

The supporting services start independently.
Door and pool init containers wait for a successful PostgreSQL query and a ZooKeeper connection, then create the Kafka billing topic using `--if-not-exists`.
The upstream pool init container also waits for the door.
No Helm hooks or external topic-creation commands are needed.

The pinned upstream chart does not expose extra init containers.
`templates/_startup.tpl` overrides its `dcache.certs.init` helper to prepend these checks while retaining certificate initialization.
The certificate container must remain last in this helper because upstream callers append its volume mount.
When upgrading the dependency, check the rendered door and pool init containers and certificate mounts.
Helm's deployment timeout bounds installation if a dependency never becomes available.
