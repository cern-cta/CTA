# gRPC frontend

The gRPC frontend exposes CTA operations to disk storage systems and delegates work to the catalogue and scheduler.

See [Workflow Frontend internals](../../docs/content/dev/internals/components/workflow-api.md) for component context and [Workflow Frontend configuration](../../docs/content/ops/deploy-and-configure/configuration/workflow-api.md) for deployment settings. Protocol definitions and generated interfaces are described under [protobuf](../../lib/protobuf/README.md).
