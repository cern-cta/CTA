# ctaops-cli

The `ctaops` command-line tool manages CTA resources and local tape hardware using the Python SDKs.

With the package installed, list the available commands:

```bash
ctaops --help
```

See the [operator guide](../../docs/content/ops/tools/ctaops.md) for installation and configuration, and [command examples](../../docs/content/ops/tools/ctaops-usage.md) for usage.
For development, see the [Python workspace](../../lib/python/README.md) and [extension guide](../../docs/content/dev/guides/python/ctaops-cli.md).
